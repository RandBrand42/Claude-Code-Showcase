How these were made

01 · BRIEF

Shared build standards

Every app was built against the same written bar for design, engineering, accessibility, mock data and verification.

02 · BUILD

Parallel specialist agents

Claude Code agents worked on separate apps at the same time, each with its own art direction and technical brief.

03 · VERIFY

A custom headless test harness

A DevTools-protocol driver (tools/browse.mjs) clicked, typed, resized and screenshotted every app and surfaced console errors.

04 · DOCUMENT

Candid READMEs

Each app ships with a purpose statement, feature tour, architecture notes and an honest post-creation summary.
